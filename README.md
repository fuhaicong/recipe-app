# 🍳 今天吃什么 · 每日食谱推荐

根据**天气、气温、季节、地域和时间**智能推荐每日食谱。可以做菜，也可以一键复制关键词点外卖。

## 快速开始

直接在浏览器中打开 `index.html` 即可，无需安装任何依赖。

## 功能

- 🌤️ **智能天气感知** — 获取当前位置的天气和温度，自动匹配适合的菜品
- 📍 **地域菜系匹配** — 自动识别所在城市，推荐当地风味或全国经典
- ⏰ **分时段推荐** — 早餐、午餐、下午茶、晚餐、夜宵，不同时段不同推荐
- 🎲 **每日不重样** — 38道精选家常菜，算法保证多样性
- 🛵 **外卖友好** — 不想做饭？一键复制关键词去美团/饿了么搜索
- 📱 **移动端优化** — PWA 支持，可添加到主屏幕
- 🔄 **离线降级** — 无网络时显示缓存的上次推荐

## 技术栈

- 纯原生 HTML / CSS / JS，零依赖
- 天气数据：[Open-Meteo](https://open-meteo.com/)（免费，无需 API Key）
- 地理编码：[Nominatim](https://nominatim.org/)（OpenStreetMap）

## 推荐算法

| 维度 | 权重 | 说明 |
|------|------|------|
| 温度 | 30% | >30°C 凉拌/冷面，20-30°C 家常小炒，10-20°C 暖汤，<10°C 炖菜火锅 |
| 天气 | 15% | 雨天→麻辣烫/酸辣汤，雪天→火锅/炖肉，极端天气→安慰食物 |
| 季节 | 20% | 春→春笋/荠菜，夏→凉拌/绿豆汤，秋→润肺羹汤，冬→进补炖菜 |
| 地域 | 10% | 匹配所在省份的菜系风格 |
| 时段 | 15% | 早餐/午餐/下午茶/晚餐/夜宵 |
| 随机 | 10% | 每日变化，保证多样性 |

附加惩罚：最近7天推荐过的菜品 -15分。
